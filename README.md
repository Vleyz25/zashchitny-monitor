# Защитный монитор (Windows)

Небольшое GUI-приложение на Python для просмотра процессов, регистрации событий запуска/завершения и анализа выбранного файла. Это вспомогательный инструмент, а не полноценный антивирус: мониторинг опрашивает видимые Windows процессы раз в две секунды и не гарантирует обнаружение скрытого вредоносного ПО.

## Возможности

- Список процессов с PID и доступным путём к исполняемому файлу.
- Во время мониторинга таблица обновляется раз в две секунды и сортируется по загрузке CPU, приведённой к шкале общей мощности процессора, как в Диспетчере задач. Для каждого процесса показываются PID и доступный путь.
- Отдельно собирается системный Interrupt/DPC CPU-счётчик Windows, если он доступен. Кнопка «Остановить и показать отчёт» выводит пиковые значения, наиболее загруженные процессы и точные совпадения с «Системные прерывания» / «System interrupts».
- Для выбранного файла: размер, дата изменения, SHA-256, статус подписи Authenticode и ограниченные эвристические индикаторы.
- Запуск проверки выбранного файла Microsoft Defender, если Defender доступен. Итог и действия защиты смотрите в «Безопасность Windows» → «Защита от вирусов и угроз» → «Журнал защиты».
- По отдельному подтверждению — перенос обычного файла в Корзину Windows. Защищённые системные каталоги исключены; файл работающего процесса не перемещается.

## Запуск из исходников

Требуется Windows 10/11 и Python 3.10 или новее.

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Для просмотра некоторых системных процессов может потребоваться запуск от имени администратора. Обычно запускайте с минимальными привилегиями.

## Сборка EXE

```powershell
pyinstaller --noconfirm --clean --onefile --windowed --name ZashchitnyMonitor main.py
```

Готовый файл: `dist\ZashchitnyMonitor.exe`. При распространении Windows может показать предупреждение SmartScreen: неподписанный исполняемый файл — ожидаемое ограничение этой сборки. Не отключайте антивирус ради запуска.

## Ограничения и безопасность

- Приложение не сканирует весь диск и не анализирует историю файла в интернете. Хеш не отправляется стороннему сервису, загрузки файла нет.
- «Системные прерывания» обычно отображаются Windows как псевдопроцесс и не имеют обычного EXE-пути. Если Windows не отдаёт путь, приложение прямо это укажет; высокая нагрузка может быть связана с драйвером или устройством, а не с файлом-майнером.
- Отсутствие подписи, использование временной папки или высокое потребление ресурсов сами по себе не доказывают заражение. У легитимных программ также бывают такие признаки.
- Опрос процессов может пропустить очень короткоживущие процессы, процессы с недоступными правами, скрытые компоненты или вредоносное ПО, отключающее защиту.
- Программа не удаляет службы, задания планировщика, записи автозагрузки, драйверы, точки восстановления и другие компоненты. Перемещение одного файла не гарантирует очистку.
- Перед изменениями изучите путь и результат Microsoft Defender. При подозрении на заражение используйте «Автономную проверку Microsoft Defender» или обратитесь к специалисту; не удаляйте системные файлы вручную.
- Запуск проверки Defender не гарантирует, что проверка прошла успешно или обнаружила угрозу: сверяйтесь с журналом защиты Windows.
